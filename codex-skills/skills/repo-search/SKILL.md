# repo-search

## 目的
在大型 repository 中快速找到真正相關的程式碼，並控制上下文大小。

## 搜尋策略
1. 從使用者需求中的專有名詞、函式、class、錯誤訊息與裝置型號開始。
2. 先搜尋入口點，再追依賴與呼叫鏈。
3. 優先取得最小必要的檔案與行範圍。
4. 搜尋不到時再擴大範圍，不要一開始讀完整 repository。
5. 修改前確認同名 symbol 是否存在多份實作。

## 嵌入式專案
優先搜尋 board 名稱、Pin、I2C address、driver class、sensor model 與初始化程式。

## 完成條件
在開始修改前，能清楚說明「哪個檔案、哪個 symbol、為何相關」。
